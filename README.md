# Atharv Manik Thorave — GitHub Pages Portfolio (Flat Folder)

All website files are together in **one folder**, with no separate `assets/` directory.

## Publish with GitHub Pages
1. Extract this ZIP into a folder on your computer.
2. Open https://github.com/atharva909/portfolio/upload/main.
3. In File Explorer, open the extracted folder, select ALL files inside it (`Ctrl+A`), and drag them to the GitHub upload page. Upload the files individually together, not the ZIP.
4. Click **Commit changes**.
5. Go to repository **Settings > Pages > Build and deployment**. Set **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)**. Click Save.
6. Your site will be available at https://atharva909.github.io/portfolio/ after publishing completes.

## Main files
- `index.html` — website (must stay at the repository root)
- `styles.css` — design and animations
- `script.js` — interactions
- `.webp`, `.jpg`, `.svg` files — portrait images and decoration, all in the SAME folder

No backend, database or separate assets folder required. Keep all files on the same level. Image files are public when deployed. Google Fonts require an Internet connection, but the rest of the site works offline.

The website includes an animated phone-free opening image, About, Skills, Education, freelance experience, projects and contact information. The requested 3D viewer is removed.
